How-To

Do these steps in order. This guide is written for someone who has never done this before.

“Take it slow, follow the How-To tab, and you’ll be fine. Every button clicked once in the first go around.

Then when you go back into the app, just click on the Hermes tab, scroll down when it loads, and launch the dashboard and gateway, assuming they don’t do it automatically for you. Then click on ‘Open in browser’ to monitor chats and make sure Hermes is completing cycles, and go back to the app and click on Trading, which is modeled after the BH dashboard.

That’s it.”

—Matthew Knight, Founder, KnightTrader BloFin
Before you start — do not skip this
  1. You need a Windows 11 PC or a Mac with admin rights (you can click “Yes” on install prompts).
  2. You need a debit card and the ability to open your bank app or approve a small verification charge.
  3. You need an email address and password you can remember — you will reuse them in the app, Coinbase, Blofin, and Nous Portal.
  4. You need about 45–90 minutes of uninterrupted time for the full first-time setup.
  5. Keep a notepad (paper or Notes app) open to copy deposit addresses, API keys, and passwords as you go.
  6. Use Chrome or Edge for exchange websites if Safari or another browser gives you login trouble.
  7. Turn off notifications or find a quiet screen so you can read each step without skipping.
  8. Plug your laptop into power — do not run this setup on battery-only if you can avoid it.
  9. Plan to buy USDT on Coinbase (Tether) — not USDC — and send USDT to Blofin (steps 12–14).
  10. After USDT arrives on Blofin, you must transfer it to USDT-M (Futures) before Hermes can trade (step 15).
  11. Budget roughly $25–$100+ for your first Coinbase USDT buy plus small network fees — start small until the full flow works once.
If something fails, stop and read the exact message. Do not keep clicking randomly. Most failures are one missed field, one wrong network, buying the wrong coin (USDC instead of USDT), or funds sitting in the wrong Blofin wallet (Funding/Spot instead of USDT-M).

Install the app
Install like any normal program. There is nothing technical here.
Windows:
  1. Open your Downloads folder and double-click the KnightTrader BloFin Setup installer.
  2. If SmartScreen asks “Windows protected your PC”, click More info → Run anyway (the app is signed; this is normal for new publishers).
  3. Click Next through the installer — default location is fine.
  4. Wait until the progress bar completes (do not cancel mid-install).
  5. Leave “Launch KnightTrader BloFin” checked if offered, or open from Start menu manually.
  6. Press the Windows key, type KnightTrader, click KnightTrader BloFin.
  7. Pin it to taskbar if you want quick access later (right-click icon → Pin to taskbar).
Mac:
  1. Open the downloaded .dmg from Downloads.
  2. Drag KnightTrader BloFin into your Applications folder when the window shows the arrow.
  3. Eject the disk image (right-click → Eject).
  4. Open Applications → double-click KnightTrader BloFin.
  5. If macOS says the app is from an unidentified developer, open System Settings → Privacy & Security → click Open Anyway for KnightTrader.
  6. Grant any permissions macOS asks for (network, etc.) — the app needs local network for Hermes.
If the app opens, you are good. If it closes immediately, read the error text and fix the first item it mentions.
What success looks like:
  1. You see the KnightTrader BloFin login screen or the How-To tab.
  2. The app stays open. It does not close by itself.
If it closes, take a screenshot of the error and fix that exact item before continuing.

Install ProtonVPN and reach an allowed country
Use this only if Blofin is blocked in your country. Do not skip the wait times.
When you need this step: If blofin.com loads normally without a geo-block message, you can skip VPN entirely. If Blofin says your region is restricted, follow every sub-step below.
Exact routine:
  1. Go to protonvpn.com in Chrome or Edge.
  2. Click Get Proton VPN or Download for Windows or Mac.
  3. Run the installer and finish setup (default options are fine).
  4. Create a free Proton account with an email you can access.
  5. Verify your email if Proton sends a link.
  6. Open the ProtonVPN app and sign in.
  7. Click Quick Connect or Connect once to confirm VPN works.
  8. Note which country flag appears — if it is the United States, you must change server (US is not allowed for Blofin in this guide).
  9. Open the ProtonVPN home screen and click Change server or pick a country from the list.
  10. Try to land in Romania, Poland, Netherlands, or Mexico.
  11. If the new country is not one of those four, wait 1 minute 40 seconds on a timer — do not click again early.
  12. Click Change server again.
  13. If it is still not allowed, wait 1 minute 50 seconds.
  14. Click Change server a third time.
  15. If you are still not in an allowed country, click Disconnect, wait 10 seconds, then click Connect.
  16. If it connects to the United States again, wait up to 10 minutes, then repeat from the Change server step.
  17. Once connected to an allowed country, open blofin.com in the same browser and confirm the site loads and lets you sign up.
  18. Leave ProtonVPN connected whenever you use Blofin in the browser until you finish steps 7–15.
Allowed countries: Romania, Poland, Netherlands, Mexico. Not allowed: Singapore, United States, Canada. If Blofin works without VPN, do not use VPN — extra hops can cause login issues.

Create Blofin API keys
The app needs three values: API Key, Secret Key, and Passphrase. The file loader can also read them from a text file.
Click by click:
  1. Sign in to blofin.com (with VPN on if you needed step 5).
  2. Click your profile icon or avatar (top right).
  3. Open API Management, API, or API Keys from the menu.
  4. Click Create API key or New API key.
  5. Name the key something simple like KT Hermes so you remember what it is for.
  6. Set permissions: enable Read if shown separately.
  7. Enable Compendium permission (required for Hermes context).
  8. Enable Trade or Trading permission (required for live orders).
  9. Enable Transfer only if you plan to move funds between Blofin wallets via API — optional for manual USDT-M transfer in step 15.
  10. If Blofin asks for IP whitelist, leave blank or add your home IP only if you know it — blank usually works for residential users.
  11. Create a strong Passphrase when prompted — write it on your notepad immediately.
  12. Click Confirm / Create and complete any 2FA Blofin requires.
  13. Blofin shows the API Key and Secret Key once — copy both before closing the dialog.
  14. Paste all three values into your notepad temporarily so you do not lose them.
  15. Open KnightTrader BloFin → Setup tab → Blofin Credentials section.
  16. Paste into API Key, Secret Key, and Passphrase fields (no extra spaces).
  17. Alternatively, save the three lines in a text file and click Load from file… to import.
  18. Confirm LIVE mode is selected (not demo) unless you intentionally use demo trading.
  19. Click Test Blofin Credentials once and wait — do not double-click.
  20. Read the result: green success means keys work; red error tells you which field failed.
  21. Do not delete the API key on Blofin until Hermes is working — you would need to recreate and re-paste.
If test fails: re-copy all three values from Blofin (Secret is shown only once at creation — if you lost it, delete the key on Blofin and create a new one). Confirm Compendium + Trade permissions. Do not move on until test succeeds.

12
Buy USDT with your debit card on Coinbase
Buy a small amount first. Card fees are higher than bank transfers. Hermes trades on Blofin USDT-M (USDT-margined perpetual futures), so you want USDT — not USDC, not BTC, not ETH — for the deposit path in this guide.
  1. Sign in to Coinbase (web or app) and confirm identity verification is complete.
  2. Click Trade, Buy, or the Buy & sell button on the home screen.
  3. In the asset search box, type USDT — do not select USDC, USD, BTC, or ETH for this guide.
  4. Select Tether (USDT) from the results.
  5. If Coinbase shows multiple USDT products, choose the standard USDT spot asset (not a wrapped or earn-only product).
  6. Enter a small amount to start (for example $25–$50) so you can learn the send/transfer flow before moving larger sums.
  7. Select your verified debit card as the payment method (not bank transfer for your first test — bank transfers are slower).
  8. Click Preview buy or Review order.
  9. Review the Coinbase fee, spread, and the total charged to your card.
  10. Confirm the asset line still says USDT before you pay.
  11. Complete any 2FA or card verification Coinbase asks for.
  12. Confirm the purchase and wait for processing.
  13. Wait until Coinbase shows the buy as Completed or the USDT balance appears in Portfolio / Assets.
  14. Click into your USDT balance and confirm the amount matches what you bought (minus fees).
  15. Leave USDT on Coinbase for now — you will send it to Blofin in step 14 after copying the deposit address in step 13.
If it fails, read the exact error. Usually it is the bank declining the card, daily card limits, or Coinbase identity verification still pending. If USDT is unavailable in your region on Coinbase, finish Coinbase verification first or use another on-ramp your region supports — but still send USDT to Blofin, not USDC.

14
Send USDT from Coinbase to Blofin
This is the most common place people lose funds. Do not rush. Match every field exactly — especially USDT and the network.
Exact Coinbase steps:
  1. In Coinbase, open Portfolio or Assets.
  2. Find USDT (Tether) in your balances.
  3. Click Send on USDT.
  4. If Coinbase asks whether you are sending to yourself or an exchange, choose the option that matches sending to an exchange / external wallet.
  5. Paste the Blofin USDT deposit address you copied in step 13.
  6. If Coinbase asks for destination tag or memo, paste the Blofin memo/tag here — leave blank only if Blofin did not give you one.
  7. Choose the network that matches Blofin exactly (same name — e.g. both say TRC20, or both say ERC20).
  8. Enter the amount of USDT to send (you can send all or leave a tiny dust amount on Coinbase).
  9. Review the network fee Coinbase shows.
  10. Click Continue or Preview send.
  11. Read the final screen: confirm coin = USDT, network matches, address matches first and last characters.
  12. Complete any 2FA or email confirmation Coinbase requires.
  13. Confirm the send.
  14. Wait for Coinbase to show the transfer as Pending or Completed.
  15. Note the transaction ID (TXID) if Coinbase shows one — useful if support needs it.
If you send the wrong coin or wrong network, the funds may be lost. Double-check USDT + network + address before confirming.
After sending — wait for Blofin to credit you:
  1. Open Blofin Assets → Deposit history or your USDT balance view.
  2. Refresh the page every few minutes. TRC20 often arrives in minutes; ERC20 can take longer depending on congestion.
  3. Wait until the deposit status shows Successful, Completed, or the USDT balance increases.
  4. Check whether the balance landed under Funding, Spot, or another wallet tab — note which one shows the USDT.
Do not continue to Hermes trading until you see the USDT on Blofin and complete step 15 (move to USDT-M).
15
Move your USDT into USDT-M (Futures) on Blofin
Hermes trades on Blofin’s USDT-margined perpetual futures (USDT-M) account. Coinbase deposits usually arrive in Funding or Spot first. Until you transfer USDT into USDT-M, the app may show zero equity and Hermes cannot open positions.
Why this step matters: Funding/Spot USDT is not the same wallet as USDT-M futures margin. You must internal-transfer on Blofin before trading.
Method A — Transfer (works from Funding or Spot):
  1. On blofin.com, sign in and open Assets (or Wallet).
  2. Click Transfer (sometimes labeled Internal transfer or an arrow icon between accounts).
  3. For From, select the account where your deposit landed — usually Funding or Spot. If you are unsure, open each tab and see which one shows your USDT balance.
  4. For To, select Futures, USDT-M, Derivatives, or Perpetual — Blofin’s label for the futures wallet. Pick the USDT-margined futures destination, not coin-margined (CM) unless you know you need CM.
  5. Select coin: USDT.
  6. Enter the amount to transfer (for your first time, you can transfer 100% or all available USDT).
  7. Click Confirm / Transfer.
  8. Complete any 2FA or email code Blofin asks for.
  9. Wait until Blofin shows the transfer as successful.
Method B — From the Futures / Trading screen:
  1. Open Blofin Futures or Trade → pick any USDT-M perpetual pair (e.g. BTC-USDT perpetual).
  2. If you see Transfer, Deposit to Futures, or a banner saying insufficient futures balance, click it.
  3. Choose From Funding or From Spot → To Futures / USDT-M.
  4. Select USDT, enter amount, confirm.
Verify USDT-M balance (required before Hermes trades):
  1. Go to Assets → Futures or USDT-M section (wording varies).
  2. Confirm USDT equity / available balance matches what you transferred.
  3. In the KnightTrader app Setup tab, click Test Blofin Credentials again — you should still see success.
  4. Later, on the Trading tab, account equity should reflect this USDT-M balance (not zero).
If transfer fails: make sure you selected USDT (not another coin), enough amount, and the correct From/To accounts. If USDT only appears under Spot, use Spot → Futures. If only under Funding, use Funding → Futures.

  3. In KnightTrader, open the Trading tab and wait for the desk to load.

  8. If a trade was placed, scroll to Open Positions and confirm rows appear.
  9. Open the app Logs tab — look for cron, gateway running, or successful Blofin test lines without repeated errors.
  10. Open the Hermes dashboard in browser and confirm the cron/job shows as scheduled or recently executed.
  11. If nothing happens after 15–20 minutes, do not deposit more — troubleshoot step 22 first.

  2. Last activity says Signal connected or shows a recent timestamp.
  3. Recent Activity shows a line like cron tick succeeded or a trade-related message.

  5. Open positions shows rows when you have USDT-M positions on Blofin.

If something breaks, fix the first error message
Do not restart from step 1. Read the exact message in Logs or on the button status, then fix that one item.
Common fixes:
  1. Login fails: retype email and password. Check caps lock. Use Forgot password? on the membership site if needed.
  2. Blofin test fails: double-check API Key, Secret Key, and Passphrase. Re-copy from Blofin API Management. Confirm Compendium permission is enabled.
  3. Equity zero / no positions: confirm USDT is in USDT-M Futures on Blofin (step 15), not only Funding/Spot. Click Test Blofin Credentials again.
  4. Deposit not showing: check Coinbase send status and Blofin deposit history — wrong network is the usual cause.
  5. Nous test fails: confirm at least $5 credits on portal.nousresearch.com and paste the full API key created after top-up.
  6. VPN is U.S.: wait the full 1:40 or 1:50, then change server again. Do not rush.
  7. Dashboard blank: open Open in Browser from the Hermes tab. The browser dashboard is the source of truth.
  8. App frozen after tray: restore from tray again, or click Reload desk on the Trading tab. Update to the latest app version if it keeps happening.
  9. No trades yet: confirm USDT-M balance, allowed VPN country, gateway running, and cron configured (steps 15, 19, 20).
  10. Cron not firing: click Auto-Configure Cron again, or paste the prompt into the Hermes dashboard manually.
  11. Computer slept: reopen the app, confirm dashboard + gateway still running, restart them if Logs say stopped.
  12. SSE 401 / signal errors in Logs: desk may still show equity via direct Blofin read if keys are saved — fix Blofin keys in Setup first; SSE is separate from your exchange balance.
If you are stuck for more than 10 minutes, stop and review the exact error text. The fix is almost always one field, one network, USDT in the wrong Blofin wallet, or one missed confirmation.
